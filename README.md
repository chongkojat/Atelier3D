# SayReal (GAM300)

## Overview
Custom 2D C++ game engine and cross-platform application suite.

## Prerequisites
* Visual Studio 2022 / C++17 Compiler
* Node.js v20+ (for web-based tools)
* CMake v3.20+

## Setup Instructions
1. **Clone:** `git clone https://github.com/Nivakin/SayReal.git`
2. **Generate Project:** `[Insert CMake or VS solution generation command]`
3. **Build:** Build via Visual Studio `SayReal.sln` or run `cmake --build build`
4. **Run:** Execute the compiled binary from the `bin/Release/` directory.
