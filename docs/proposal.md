# SayReal: Project Proposal

## Concept
SayReal is a procedural 3D interior design desktop application. 

## Core Mechanics & Features
* **Room Generation:** The user draws the physical dimensions of the room.
* **Density Control:** A slider allows the user to choose the density of the furniture design (None, Low, Med, High).
* **Stylistic Themes:** Users can select specific design aesthetics (e.g., Japanese or Scottish).
* **AI Integration:** An underlying AI system processes the dimensions, density, and style inputs to procedurally generate distinct room designs.

## Technology Stack
* **Game Engine:** Unreal Engine
* **Target Platform:** Desktop
